Reflection

This assignment was probably the most challenging one. Reading through the lesson content, the individual concepts made a lot of sense, but once I started getting my hands dirty with putting it all together it started to feel like my web app was a Frankenstein of calcite design and web components. It required a lot of research and referring back to lesson content to understand how different components integrated with each other.

I started by applying the calcite date picker from the lesson content to my lesson 7 web app, but I quickly realized this was an awkward user experience since the data I’m using only includes years and not days or months. I didn’t want the user to pick two months within the same year and get hurricane tracks from that entire year. Of course, the date picker in calcite does not include the option to only allow for year selection, so I decided to pivot and use a drop down instead.

I researched how to implement pulling the years from the feature service to be included in the drop down, since hardcoding 100+ years sounded too time consuming, but I reached a limit where I was breaking more code than finding success. I decided to hardcode the last 10 years of data available from the feature service into the dropdown and move forward with that. In the future, I’d like to implement the code that allows this to be gathered from the feature service so that when the feature service is updated with a new year, this automatically loads into the drop down.

I adapted code from this tutorial to implement the results list and pop ups in calcite. I believe a lot of my struggle was due to starting with the lesson 7 code, adding in calcite and then trying to implement web components after - looking back I think I would have saved time by starting fresh utilizing web components and implementing calcite where necessary.

I also had the unfortunate event of finding out the feature service I used in lesson 7 was broken and resorting to a new feature service which had different field names and data types. It wasn’t too time consuming to reroute my code, however I spent a while just trying to get my lesson 7 app code working with the new data and I think the more efficient approach would have been starting from scratch.

Overall, I ran into a few hiccups where I was wishing this assignment was a little more structured and focused on applying specific elements in a specific order. I will definitely need to review how these systems talk to each other before tackling the final project.
